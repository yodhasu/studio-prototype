# Directives (Layer 1)

This directory contains Standard Operating Procedures (SOPs) and Markdown instructions. 

## How to use
1. **Identify the goal**: What is the higher-level task?
2. **Draft the directive**: Create a `.md` file here describing the inputs, process, tools to use, and expected outputs.
3. **Point the Agent**: References these directives when you want the Agent to perform a specific orchestrated task.

## Key Principles
- Be descriptive but concise.
- Define edge cases.
- Specify which execution scripts (Layer 3) to use.
